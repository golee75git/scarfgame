수정은 기존 프로젝트의 자체 개발 코드만 기반으로 구현한다.
수정된 내용은 도움말을 비롯하여 프로젝트에 영향을 받는 모든 파일 적용하고 검증한다. 
수정작업중에 더 좋은 방법이 있거나 의문이 있으면 작업을 진행하지 말고 질문해줘.
글자는 상업적 사용이 허용된 OFL 글꼴 사용하고 프로젝트에 사용된 글꼴이 OFL 글꼴인지도 확인해줘.
다른곳 인터넷, GitHub, 경쟁 제품, 특허 문서 또는 외부 소스코드의 구현을 복사·번역·변형하여 사용하지 않는다.
데이터 구조, 함수 구조, 상태 전이 로직을 현재 프로젝트에 맞게 처음부터 독립적으로 설계한다.
일반적이고 불가피한 관용 코드 외에는 외부 구현과 유사한 명칭, 주석, 처리 순서 및 UI 문구를 사용하지 않는다.
새로 작성하거나 변경한 파일과 재사용한 기존 파일을 구분하여 작업 결과에 표시한다.
외부 라이브러리를 새로 추가하지 않는다. 반드시 필요한 경우에는 먼저 라이브러리명, 버전, 출처, 라이선스와 추가 이유를 제시하고 코드에는 반영하지 않는다.
